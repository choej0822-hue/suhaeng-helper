# 수행평가 도우미

학생이 수행평가·보고서를 준비할 때 쓰는 무료 웹 도구 모음입니다.
서버 없이 HTML, CSS, JavaScript만으로 동작하는 **정적 사이트**라서 GitHub Pages에 무료로 올릴 수 있습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | **첫 화면 = 출처(참고문헌) 표기 만들기 도구** (메인 기능) |
| `dday.html` | 수행평가 D-day 정리 도구 (보조 기능) |
| `about.html` | 사이트 소개 페이지 (애드센스 승인에 필요) |
| `privacy.html` | 개인정보처리방침 (애드센스 승인에 필요) |
| `style.css` | 모든 페이지가 같이 쓰는 디자인 |

## 코드 설명

### 출처 표기 도구 (`index.html`)
아래쪽 `<script>` 안이 기능 코드이고, 번호 주석으로 나눠져 있어요.

1. **`TYPES`**: 자료 종류(책, 기사, 웹사이트, 논문)마다 어떤 입력칸이 필요한지 적어 둔 표예요. 새 자료 종류(예: 영상)를 추가하고 싶으면 여기에 한 덩어리를 더 넣으면 돼요.
2. **날짜 함수들**: `2024-03-05` 같은 날짜를 `2024.3.5.`(학교 양식)나 `2024, 3월 5일`(APA)로 바꿔요.
3. **`build()`**: 핵심 함수예요. 입력값을 받아서 양식 규칙대로 출처 문장을 이어 붙여요. 빈칸은 자동으로 건너뛰어요. 기울임체가 필요한 곳은 `*별표*`로 표시해 두고, 화면에 보여줄 땐 기울임체로, 복사할 땐 별표를 지운 글자로 바꿔요.
4. **화면 그리기**: 탭(자료 종류/양식)을 누르면 입력칸과 미리보기를 다시 그려요. 글자를 입력할 때마다 `update()`가 불려서 미리보기가 바로 바뀌어요.
5. **참고문헌 목록**: 추가한 출처를 브라우저의 `localStorage`(그 기기 브라우저 안의 작은 저장 공간)에 저장해요. 가나다순으로 정렬해서 보여주고, 한 번에 복사할 수 있어요.

### D-day 도구 (`dday.html`)
- `daysLeft()`: 오늘과 마감일 사이의 날 수를 계산해요.
- `label()`: 남은 날에 따라 `D-5`, `D-DAY`, `D+2` 글자와 색(3일 이내는 주황, 당일은 빨강, 지난 건 회색)을 정해요.
- 목록은 역시 `localStorage`에 저장돼서, 서버나 회원가입 없이도 다음에 들어오면 그대로 남아 있어요.

### 각 페이지 아래 설명글
도구 아래에 있는 "출처 표기, 왜 해야 하나요?" 같은 글은 **검색 노출(SEO)과 애드센스 승인**을 위한 거예요. 구글은 내용이 있는 페이지를 좋아해서, 도구만 있는 페이지보다 설명글이 있는 페이지가 검색에 더 잘 걸려요.

## 배포 방법 (GitHub Pages)
1. GitHub에서 새 저장소(public)를 만들고 이 폴더의 파일을 모두 올려요.
2. 저장소의 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main` / `(root)`로 고르고 저장해요.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 사이트가 열려요.
